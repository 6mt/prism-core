# Prism 贡献者许可协议（CLA）草案

> 状态：**草案**（正式启用前请律师审阅）。目的：保留对贡献代码再许可（含商业授权）的权利。

## 个人贡献者

当你向本项目的任何仓库提交贡献时，即在遵守 Apache-2.0（core）或各包声明的许可证基础上，
额外授予项目维护者以下非独占、永久、全球、免版税的权利：

1. **版权许可**：以现有或未来出现的任何形式使用、复制、修改、再许可、分发你的贡献，
   包括将其并入 AGPL-3.0 版本或商业授权版本。
2. **专利许可**：你就贡献中所含的、由你拥有的专利权利，授予维护者及其被许可方
   制作、使用、销售、许诺销售、进口的永久免版税许可。
3. 你声明：贡献由你原创创作，或你有权按本协议授予上述许可；你知悉提交公开记录
   （作者信息与提交历史）将永久保留。

## 企业贡献者

由雇员在受雇期间做出的贡献视为其雇主授权的贡献，雇主需接受同等条款（可另签企业 CLA）。

---

**为什么需要 CLA**：Prism 采用 open-core 模式（core=Apache-2.0，适配器=AGPL/商业双许可）。
没有 CLA，任何外部贡献者的代码都可能卡死未来的商业再许可。签署门槛保持最低
（提交即视为接受，首次 PR 时机器人确认），避免伤害社区参与。
